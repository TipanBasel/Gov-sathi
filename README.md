# GovSathi 🇳🇵

**GovSathi** is an AI-powered Nepali legal assistant that helps users understand Nepal's government laws and services through natural-language questions. It uses **Retrieval-Augmented Generation (RAG)** to retrieve relevant information from legal documents and generate answers in Nepali.

## Features

* Nepali-language AI assistant
* RAG-based question answering
* FAISS-based document retrieval
* Ollama + Gemma 2B for response generation
* FastAPI backend
* Focus on traffic laws and citizenship services

## Technologies

* Python
* FastAPI
* FAISS
* Ollama
* Gemma 2B
* RAG
* Tesseract OCR
* PDF Processing

## Objective

The main goal of GovSathi is to make Nepal's government laws and services easier to understand by providing a simple AI assistant that can answer users' questions in Nepali.
